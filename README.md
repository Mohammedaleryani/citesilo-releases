# Citesilo releases

Installers for [Citesilo](https://github.com/Mohammedaleryani/citesilo), a
work diary that writes itself.

The latest Windows installer is on the
[releases page](https://github.com/Mohammedaleryani/citesilo-releases/releases).
Download it, run it, and the app updates itself from here after that.

This repository holds only the built installers. The source lives elsewhere.
